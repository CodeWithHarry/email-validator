## Overview

Email Validator is a simple web application built with HTML, CSS, and JavaScript. It allows users to validate the format of email addresses. This project demonstrates basic front-end web development skills, including form handling and regular expression usage for validation.

## Features

- Real-time email validation
- User-friendly interface
- Lightweight and fast
- Easy to integrate into other projects

## Installation

To get a local copy up and running, follow these simple steps:

### Prerequisites

- Web browser (Chrome, Firefox, etc.)

### Steps

1. Clone the repository:
   ```bash
   git clone https://github.com/CodeWithHarry/email-validator-html-css-js.git
2. Navigate to the project directory:
   ```bash
   cd email-validator-html-css-js
3. Open `index.html` in your web browser.

### Usage

1. Open the Email Validator in your web browser.
2. Enter an email address in the input field.
3. The application will validate the email format in real-time and display a message indicating whether the email is valid or invalid.

## Code Explanation

### HTML
The `index.html` file contains the structure of the application, including the input field for email addresses and the validation message.

### CSS
The `styles.css` file provides the styling for the application, ensuring a clean and user-friendly interface.

### JavaScript
The `script.js` file contains the logic for email validation. It uses a regular expression to check the format of the entered email address and updates the validation message accordingly.
